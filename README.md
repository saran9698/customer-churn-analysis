# Customer Churn Analysis

## Project Overview
Customer Churn Analysis predicts whether a customer is likely to leave a company based on customer behavior and service usage patterns.

## Objective
To identify customers at risk of churn and help businesses improve customer retention.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Machine Learning Prediction
- Customer Retention Insights

## Algorithms Used
- Logistic Regression
- Random Forest Classifier

## Dataset
Customer Churn Dataset from Kaggle.

## Results
The model predicts customer churn with good accuracy and helps identify important factors affecting churn.
